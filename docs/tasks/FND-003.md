### Failure propagation

Each essential step is a single `run` command with no `shell:` override, so
GitHub Actions executes it with the default `bash -e {0}`. A nonzero exit code
from any of `bun install`, `bun run typecheck`, `bun run build`,
`bun run test`, or `bun audit` fails the job. No step masks a failure status.

## Security notes

- **Action pinning:** both external actions are pinned to full 40-character
  immutable commit SHAs, with the human-readable version in a trailing comment
  for auditability. No action is referenced by tag or branch.
- **Token permissions:** `permissions: contents: read` only. The workflow
  requests no write scope, so the `GITHUB_TOKEN` cannot modify repository
  contents.
- **Credential exposure:** checkout uses `persist-credentials: false`, so the
  token is not left in the local git config for subsequent steps.
- **Secrets:** no repository secrets, personal tokens, or deployment
  credentials are referenced.
- **Dependency installation:** `--frozen-lockfile` guarantees CI installs
  exactly what `bun.lock` records and cannot silently update the lockfile.
  `--ignore-scripts` prevents dependency lifecycle scripts from executing.
- **Audit:** `bun audit` runs as a required step and is not suppressed.
- **Failure integrity:** no `continue-on-error`, no `|| true`, no ignored exit
  codes.

Limitations of this security posture:

- `bun audit` covers known dependency vulnerability advisories only. It is not
  a license review, not a dependency-ownership review, and not a complete
  supply-chain verification (D-066 requires vulnerability, license, and
  transitive-dependency scanning; only the vulnerability portion is automated
  here).
- No SBOM, provenance, or artifact signing is produced.
- No branch protection is configured, so a failing run does not yet block a
  merge. Changing repository settings requires owner approval and is out of
  scope for this task.
- `--ignore-scripts` is safe for the current dependency set because no
  dependency in `bun.lock` defines an install lifecycle script. A future
  dependency that genuinely requires one would need a separately reviewed
  change.
