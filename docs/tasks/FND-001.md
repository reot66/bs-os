## Incident — corrupted documentation blob (resolved)

During the initial commit `c676d1f`, `git add` captured
`agent/architecture/ARCHITECTURE_MAP.md` while the working-tree copy of that
file transiently contained the FND-001 task prompt text from line 38 onward,
replacing the remainder of the architecture diagram. The index retained that
corrupt blob (20616 bytes / 1033 lines) and it was committed and pushed.

- Scope of contamination: exactly 1 file. Verified via
  `git grep -l "OpenCode Development Task" HEAD --`, which returned only
  `agent/architecture/ARCHITECTURE_MAP.md`.
- The other 73 files under `agent/` were unaffected.
- The genuine 85-line architecture map (1740 bytes) was intact in the working
  tree and was restored by a separate ordinary forward commit.
- No amend, no force-push, and no history rewrite were used. The corrupt blob
  remains visible in the history of `c676d1f` on both remotes.
- This incident is reported here rather than silently corrected, per the task's
  prohibition on modifying approved documents without authorization.
