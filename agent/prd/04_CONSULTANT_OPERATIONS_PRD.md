# PRD — Consultant / Customer Success Operations

## Goal
پشتیبانی مدل Services + Platform و onboarding/assessment مشتریان.

## Basic Candidate
- Client/Business list
- Assessment record
- Setup checklist
- Internal tasks
- Notes
- Progress/status
- Link to business health/modules

## Advanced Candidate
Basic + standardized playbooks, growth plans, recurring reviews, SLA/task automation, team workload, partner handoff, outcome/KPI tracking, recommendation workflows.

## Boundary
این Module جای Project Management عمومی مشتری نیست؛ ابزار Customer Success/Consulting تیم/Partner است.

## Capability Level Gate
**Level هنوز انتخاب نشده است مگر Owner صریحاً انتخاب کند.** قبل از implementation Agent باید Basic و Advanced را با scope دقیق ارائه کند.

## Engineering Baseline
در هر Level تمام Foundation Rules مربوط به Security, tenancy, tests, observability, data ownership, migrations, contracts و audit رعایت می‌شوند.
