# PRD — Customer Support / Helpdesk

## Basic Candidate
- Ticket/conversation
- Customer linkage
- Assignee/status/priority
- Notes
- Email/form intake adapters
- SLA basics later depending selected level

## Advanced Candidate
Basic + multi-channel inbox, teams, SLA/escalation, macros, knowledge base, automation/routing, CSAT, advanced reporting, AI assist future.

## Boundary
Support Module داده Customer را duplicate نمی‌کند و channel integrations از adapters می‌آیند.

## Capability Level Gate
**Level هنوز انتخاب نشده است مگر Owner صریحاً انتخاب کند.** قبل از implementation Agent باید Basic و Advanced را با scope دقیق ارائه کند.

## Engineering Baseline
در هر Level تمام Foundation Rules مربوط به Security, tenancy, tests, observability, data ownership, migrations, contracts و audit رعایت می‌شوند.
