# PRD — Project Management

## Basic Candidate
- Project
- Task
- Assignee
- Status
- Priority
- Due date
- Comments/activity
- List/Kanban basics

## Advanced Candidate
Basic + milestones, dependencies, custom fields, templates, recurring tasks, time tracking, workload, advanced views, automation, guest/client collaboration, reports.

## Boundary
این Module general business PM است و با Consultant Operations داخلی یکی نیست.

## Capability Level Gate
**Level هنوز انتخاب نشده است مگر Owner صریحاً انتخاب کند.** قبل از implementation Agent باید Basic و Advanced را با scope دقیق ارائه کند.

## Engineering Baseline
در هر Level تمام Foundation Rules مربوط به Security, tenancy, tests, observability, data ownership, migrations, contracts و audit رعایت می‌شوند.
