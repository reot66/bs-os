# Definition of Done

Feature فقط وقتی Done است که موارد applicable کامل باشند:

- [ ] Selected Capability Level confirmed by Owner
- [ ] Problem/outcome satisfied
- [ ] Correct Domain Owner
- [ ] Data ownership/schema clear
- [ ] Migration safe/backward-compatible
- [ ] API/contracts typed and validated
- [ ] Permissions/scopes implemented
- [ ] Entitlements/usage metrics where applicable
- [ ] Configuration/flags defined where applicable
- [ ] Events versioned/handled idempotently where applicable
- [ ] Audit actions defined
- [ ] Structured logs/metrics/error codes added
- [ ] Tenant isolation negative tests pass
- [ ] Unit/integration/contract tests pass
- [ ] Critical E2E updated
- [ ] Security/privacy/data lifecycle reviewed
- [ ] RTL/accessibility UX baseline
- [ ] Documentation/manifest updated
- [ ] Rollout/rollback strategy ready
- [ ] No silent scope creep
